# Contributing

Thanks for helping the Commons.

## Good contributions

- Fix a reproducible bug.
- Improve keyboard, touch, responsive, or screen-reader behavior.
- Make a game rule easier to understand.
- Add a fictional event that satirizes systems and incentives rather than a real person.
- Improve balance without making one strategy obviously dominant.

## Before opening a pull request

1. Keep the game dependency-free unless there is a strong reason to change that.
2. Test the start screen, one release cycle, reinvestment, and the final result dialog.
3. Test at one desktop and one narrow mobile width.
4. Preserve the fictional framing. Do not add real company logos, real-person caricatures, or unverified legal claims.
5. Explain the player-facing effect of your change.

Be constructive and assume good faith. Harassment, personal attacks, and discriminatory behavior are not welcome.
