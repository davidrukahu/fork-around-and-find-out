## Page description

**Fork Around & Find Out** is a fast arcade satire about the impossible balancing act behind open-source communities.

Catch commits, fixes, documentation, and volunteer hours. Avoid bugs, invoices, and tiny parachuting lawyers. Let a fictional commercial host make money—then reinvest enough value to stop the community from burning out.

Survive five increasingly chaotic release cycles and defeat **The Extraction Engine**.

- Three-to-five-minute runs
- Mouse, touch, and keyboard controls
- No login
- No tracking
- Mobile friendly
- Fictional companies and characters
- Open-source code

Everything in the game is fictional. It satirizes systems and incentives; it does not reenact a lawsuit or make claims about real people or companies.
